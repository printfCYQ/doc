## 0. 先搞清楚：一堆名词到底是啥关系

新手最容易被 AI、机器学习、深度学习、大模型这几个词绕晕。用"交通工具"打个比方：

- **AI（人工智能）**：最大的框，目标是让机器做原本需要人类智能的事。相当于"交通工具"这个大类。
- **机器学习（ML）**：AI 的一个分支，核心思路是"不写死规则，让程序从数据里自己学规律"。相当于"汽车"——是交通工具的一种实现方式。
- **深度学习（DL）**：机器学习的一个分支，专门用"多层神经网络"来学。相当于"电动汽车"——是汽车里的一种动力形式。
- **大模型 / LLM**：深度学习在"语言"上做到极致的产物（代表是 GPT 这类），靠 Transformer 架构 + 海量数据训练出来。相当于"某款具体的电动跑车"。

一句话：**AI ⊃ 机器学习 ⊃ 深度学习 ⊃ 大模型**。你后面看到这些词，先想清楚它在哪一层，就不会乱。

另外一个必须分清的点：**算法（本站的算法分类）** 讲的是数据结构与刷题那种" deterministic 步骤"；**机器学习** 讲的是"从数据里拟合规律"，两者不是一回事，但数学底子（尤其是复杂度分析）是共通的。

## 1. 起步：你需要什么，以及环境怎么装

### 1.1 先别急着学数学

很多人被"学 AI 要先啃完高数线代"劝退，其实没必要。实操派的做法是：**用到哪补到哪**。下面三块数学，前面知道个大概、能看懂公式符号就行，真写代码时再回头补：

| 数学 | 在 AI 里干嘛用 | 入门要到什么程度 |

| 微积分 | 反向传播本质是求梯度（导数） | 懂"导数=变化率"、链式法则 |
| 概率统计 | 评估模型、贝叶斯、分布 | 懂均值方差、条件概率、贝叶斯公式 |

## 2. 机器学习主线：从数据到模型

机器学习的套路基本固定，记住这条流水线就不会慌：

```
原始数据 → 清洗 → 特征工程 → 选模型 → 训练 → 评估 → 调参 → 部署
```

### 2.1 训练集 / 验证集 / 测试集

- **训练集**：模型拿它来学规律
- **验证集**：调参数、选模型时看效果（模型没直接拿它训练，但你在它上面挑模型）
- **测试集**：最后用来报成绩，**全程不能碰**，否则等于考试前偷看了答案

常见切法 8:1:1 或 7:2:1。

### 2.2 过拟合与欠拟合

这是新手必踩的坑，先建立直觉：

- **欠拟合**：模型太简单，连训练集都学不好（比如用直线去拟合曲线数据）
- **过拟合**：模型把训练集的噪声都背下来了，换个新数据就懵

解决方法：加数据、简化模型、正则化（L1/L2）、早停、 dropout（深度学习里）。

### 2.3 评估指标：别只会看准确率

- **分类问题**：准确率、精确率（precision）、召回率（recall）、F1、ROC-AUC
- **回归问题**：MSE（均方误差）、MAE（平均绝对误差）、R²

一句话提醒：数据不平衡时（比如 99% 是阴性），准确率 99% 也可能是个废物模型——这时候要看召回率。

### 2.4 经典算法：先用 sklearn 跑通

scikit-learn 是机器学习的"标准教科书库"，API 统一，先把下面这些跑一遍：

| 类型 | 算法 | 一句话用途 |
|---|---|---|
| 回归 | 线性回归、岭回归 | 预测连续值（房价、分数） |
| 分类 | 逻辑回归、SVM、k-NN、决策树、随机森林、XGBoost | 预测类别（ spam / 非 spam） |
| 聚类 | k-Means、DBSCAN | 无标签时自动分组 |
| 降维 | PCA、t-SNE | 把高维数据压到 2D 方便看 |

```python
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

X = np.array([[1],[2],[3],[4],[5]])
y = np.array([52, 61, 70, 81, 90])

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)
model = LinearRegression()
model.fit(X_train, y_train)

print("权重 w =", model.coef_, "偏置 b =", model.intercept_)
pred = model.predict(X_test)
print("测试集 MSE =", mean_squared_error(y_test, pred))
```

这就是最简单也最经典的"监督学习"：给模型看 `(输入, 输出)` 成对的数据，它学出 `y ≈ w·x + b`。

练习：把上面模型换成 `LogisticRegression`（配合一组分类数据）或 `KMeans`（无标签数据），感受 API 几乎一模一样。

## 3. 深度学习：当神经网络变深

机器学习处理"特征"大多要人手工提；深度学习牛在**它能自己从原始数据里学特征**，前提是数据够多、模型够深。

### 3.1 神经网络的基本单元

一个神经元做的事：`输出 = 激活函数( w·x + b )`。

- 一层层叠起来就是"多层感知机"（最简单的前馈网络）
- **激活函数**：给网络引入非线性（否则多层叠起来还是一条直线）。常用 ReLU：`f(x)=max(0,x)`
- **损失函数**：衡量预测和真实的差距（回归用 MSE，分类用交叉熵）
- **反向传播**：用链式法则把损失对每一个参数的"梯度"算出来
- **梯度下降**：顺着梯度反方向更新参数，让损失变小：`θ ← θ - α·∇θJ`

`α` 叫学习率，太大模型发散，太小学得慢——这是调参第一课。

### 3.2 三大经典结构

| 结构 | 擅长 | 典型场景 |
|---|---|---|
| **CNN（卷积网络）** | 提取空间局部特征 | 图像分类、目标检测 |
| **RNN / LSTM** | 处理序列、有记忆 | 早期文本、时间序列（现在多被 Transformer 取代） |
| **Transformer** | 并行处理序列 + 注意力机制 | 现在的 NLP 主力，也是大模型底座 |

### 3.3 上手 PyTorch

PyTorch 是当下最主流的深度学习框架，张量（tensor）概念和 NumPy 数组很像，但能跑 GPU。

```python
import torch

x = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
print(x.shape, x.dtype)          # 看维度和类型
print(x * 2)                      # 张量运算
print(x.cuda())                   # 搬到 GPU（有显卡时）
```

后面搭网络用 `torch.nn`：定义 `nn.Module` 子类、`forward` 写前向、用 `nn.CrossEntropyLoss` 算损失、`torch.optim.Adam` 优化。这块建议专门花一周跟着官方 tutorial 敲。

练习：用 PyTorch 搭一个只有一层的线性网络，手动用梯度下降拟合第 2.4 节的 `hours→score` 数据，观察 loss 是否下降。

## 4. 大模型 LLM：现在最该关注的一块

如果你时间有限、只想学"当下最有用"的 AI，直接看这章。大模型（以 GPT、Claude、Llama 为代表）把 AI 从"专用工具"变成了"通用助手"。

### 4.1 它到底是怎么工作的（一句话版）

大模型本质是**一个超大的、预测"下一个词"的神经网络**。它读了海量文本后，学会了对任意输入续写出合理的下文。聪明的地方在于：它把"知识"压缩进了参数里，你用**提示词（prompt）** 跟它对话，它就能调用这些压缩知识。

### 4.2 Transformer 是底座

第 3.2 节提到的 Transformer，核心是一个叫 **注意力（Attention）** 的机制：让模型在处理每个词时，动态决定"该重点关注输入里的哪些词"。公式长这样（不用背，知道它算的是"相关性加权"即可）：

$$\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

### 4.3 预训练 vs 微调

- **预训练**：在海量无标注文本上练"续写"，得到基座模型。这一步算力需求极大，普通人不用做。
- **微调（Fine-tuning）**：在预训练模型上，用你自己的少量数据继续训练，让它擅长某个具体任务。
- **参数高效微调（PEFT / LoRA）**：只训练模型里很小一部分参数（低秩适配），显存需求骤降，个人电脑 + 消费级显卡就能玩。现在主流做法。

### 4.4 提示工程（Prompt Engineering）

不训练模型、只靠"会问问题"就能显著提升效果。几个实用套路：

- **给角色**："你是一个资深 MySQL 老师…"
- **给示例（few-shot）**：先给 2~3 个问答样例，再问新问题
- **拆步骤**：让模型"一步一步想"（思维链，Chain-of-Thought）
- **限定输出格式**：要求返回 JSON / 表格，方便程序解析

### 4.5 RAG：给模型接上你的私有知识

大模型的知识停在训练截止日，且不知道你的内部文档。RAG（检索增强生成）解决这个：

```
用户提问 → 把问题转成向量 → 去知识库里搜最相关的几段 → 把这几段塞进 prompt → 让模型基于它们回答
```

关键点：**Embedding（嵌入）** 把文字变成向量，**向量数据库**负责按相似度快速检索。

```python
# RAG 伪代码（思路，不是可直接跑的实现）
def answer(question):
    q_vec = embed(question)                       # 问题转向量
    chunks = vector_db.search(q_vec, top_k=3)     # 检索最相关片段
    prompt = f"根据下面资料回答问题：\n{chunks}\n\n问题：{question}"
    return llm(prompt)                            # 让大模型基于资料作答
```

RAG 和 Agent 的具体做法、可运行代码、工具选型，单独写在 [AI 大模型应用（实战指南）](./llm-app.md) 里，想动手直接看那篇。

### 4.6 Agent：让模型能"动手"

Agent（智能体） = 大模型 + 工具调用 + 记忆。模型不再只动嘴，而是能调用搜索、执行代码、查数据库，并多轮迭代完成任务。这是 2025 年以来最热的方向（LangChain / LangGraph 是常用框架）。

练习：注册一个能跑本地模型的环境（见下章 Ollama），用一条 prompt 让模型把一段中文翻译成英文并输出 JSON，体会"限定格式"的威力。

## 7. 常见坑（新手最容易栽的地方）

1. **一上来就啃数学教材**：学到用不上，三个月放弃。先跑通代码，缺啥补啥。
2. **只看不敲**：AI 是手艺活，看懂不等于会写。每个示例都要自己跑。
3. **数据集不切分就全拿来训**：等于考试偷看答案，线上一塌糊涂。
4. **盲目追大模型**：小任务用 sklearn 十分钟解决，别上来就微调 LLM。
5. **忽视数据质量**：垃圾进垃圾出，清洗和特征工程往往比换模型更提分。
6. **显存爆了就加数据**：先试减小 batch、用 LoRA、用更小的模型。
7. **把模型输出当真理**：大模型会"一本正经胡说"（幻觉），生产环境要加校验和引用。

## 8. 推荐的进阶路线（按顺序走）

下面这条线，普通自控力的人大概 6~12 个月能走到"能做项目"：

**阶段 1 · Python + 数据处理（2~4 周）**
目标：熟练 NumPy / Pandas / 画图。对应本站 Python 笔记 + 上面[第 1 章](#_1-起步-你需要什么-以及环境怎么装)。

**阶段 2 · 经典机器学习（4~6 周）**
目标：用 sklearn 跑通回归/分类/聚类，理解评估指标和过拟合。对应[第 2 章](#_2-机器学习主线-从数据到模型)。做 2~3 个 Kaggle 入门赛。

**阶段 3 · 深度学习 + PyTorch（6~8 周）**
目标：能手搭 CNN 做图像分类、理解反向传播。对应[第 3 章](#_3-深度学习-当神经网络变深)。跟 PyTorch 官方 60 分钟入门。

**阶段 4 · Transformer 与 Hugging Face（4~6 周）**
目标：用 `transformers` 微调一个文本/图像小模型。对应第 4.1~4.3 节。

**阶段 5 · 大模型应用（持续）**
目标：用 Ollama 跑本地模型，做 RAG + Agent 小项目。对应第 4.4~4.6、[第 5 章](#_5-工具链-别重复造轮子)。

**阶段 6 ·（可选）深入与工程化**
读经典论文、学 MLOps（实验跟踪、模型部署监控）、做大项目放进简历。

### 阶段 5 之后可以做的项目清单
- 一个"基于个人笔记的问答机器人"（RAG 入门首选）
- 一个"自动总结文章并转 JSON"的小工具（Prompt 工程）
- 一个"能查天气/跑代码"的 Agent（工具调用）
- 微调一个垂直领域小模型（如客服问答）

## 10. 新手最常问的几个问题

**Q1：数学不好能学 AI 吗？**
能。先跑通代码，遇到看不懂的公式再补对应那一小块。很多工程师工作多年也没手写过高数推导。

**Q2：要先学机器学习再学大模型吗？**
建议有个 ML 底子（阶段 1~2），但不用精通。现在完全可以"先玩 LLM 应用（RAG/Agent）"再回头补原理。

**Q3：没有 GPU 能学吗？**
能。阶段 1~2 用 CPU 足够；阶段 3 用 Colab/Kaggle 免费 GPU；阶段 5 用 Ollama 跑量化小模型，消费级显卡甚至纯 CPU 都能跑。

**Q4：学 PyTorch 还是 TensorFlow？**
新手直接 PyTorch，生态和社区现在更友好。

**Q5：AI 会取代程序员吗？**
短期内是"增强"不是"取代"。会用 AI 工具的人效率翻倍，这正是你学它的理由。
