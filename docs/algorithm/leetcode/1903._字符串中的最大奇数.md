从后往前找，找到奇数，（从头取到这个位置）就是最大奇数

```javascript
var largestOddNumber = function (num) {
    let res = "";
    for (let j = num.length - 1; j >= 0; j--) {
        if (num[j] % 2 !== 0) {
            return num.substr(0, j + 1);
        }
    }
    return res;
};
```
