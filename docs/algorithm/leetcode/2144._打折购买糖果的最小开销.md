-   数组从小到大排序
-   每隔三位的糖果可以被赠送（即 i%3 === 2）
-   求不能赠送的糖果的和 （即 i%3 != 2） 的和

```javascript
/**
 * @param {number[]} cost
 * @return {number}
 */
var minimumCost = function (cost) {
    cost.sort((a, b) => b - a);
    let res = 0;
    for (let i = 0; i < cost.length; i++) {
        if (i % 3 != 2) {
            res += cost[i];
        }
    }
    return res;
};
```
