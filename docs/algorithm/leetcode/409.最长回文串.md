### map

字符串s中，每个出现的字符为（ch）

-   ch 出现次数为 偶数时： ch出现的次数都可以被使用
-   ch 出现次数为 奇数时（并且大于2）： ch长度 - 1 的次数可以被使用
-   ch 出现次数为 1时： 可以作为回文串的中心（只能用一次）

```javascript
/**
 * @param {string} s
 * @return {number}
 */
var longestPalindrome = function (s) {
    if (s.length === 1) return 1;
    let res = 0;
    const map = new Map();
    for (let i = 0; i < s.length; i++) {
        map.has(s[i]) ? map.set(s[i], map.get(s[i]) + 1) : map.set(s[i], 1);
    }
    for (let item of map.values()) {
        if (item % 2 === 0) {
            res += item;
        } else if (item > 2) {
            res += item - 1;
        }
    }
    return res === s.length ? res : res + 1;
};
```

### set

-   利用 set 计数，当set中已存在（即已经成对，count+=2，并删除set中的记录）
-   最后判断set中是否还有数据 ： 有则可以作为回文串的中心（只能用一次）

```javascript
var longestPalindrome = function (s) {
    var set = new Set();
    var count = 0;
    for (var i = 0; i < s.length; i++) {
        if (set.has(s[i])) {
            count += 2;
            set.delete(s[i]);
        } else {
            set.add(s[i]);
        }
    }
    return set.size > 0 ? count + 1 : count;
};
```
