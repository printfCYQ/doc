### sort

-   第一步对（胃口值，尺寸）进行从小到大的排序
-   索引 i，j 分别对应 （胃口值和尺寸） 数组
-   当前饼干尺寸 满足 当前 胃口值 （i++, j++）,否则（不满足时，j++）直到找到满足当前胃口值当饼干。
-   当饼干找完，或者 胃口值都被满足时，循环停止

```javascript
var findContentChildren = function (g, s) {
    g.sort((a, b) => a - b);
    s.sort((a, b) => a - b);
    let i = 0;
    let j = 0;
    while (i < g.length && j < s.length) {
        if (g[i] <= s[j]) {
            i++;
            j++;
        } else {
            j++;
        }
    }
    return i;
};
```
