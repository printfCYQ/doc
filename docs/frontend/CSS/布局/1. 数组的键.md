## 3.为什么span是行级元素

-2.png)

> `span`是行级元素是因为在浏览器默认样式表内没有给`display`属性赋值，`display`默认为`inline`
> 
> `div`是块级元素：`display:block`
> 【MDN】HTML 标准中[块级元素](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Block-level_elements)和[行内元素](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Inline_elements)的区别至高出现在 4.01 标准中。在 HTML5，这种区别被一个更复杂的[内容类别](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Content_categories)代替。”块级“类别大致相当于 HTML5 中的[流内容(en-US)](https://developer.mozilla.org/en-US/docs/Web/HTML/Content_categories#flow_content)类别，而”行内“类别相当于 HTML5 中的[措辞内容(en-US)](https://developer.mozilla.org/en-US/docs/Web/HTML/Content_categories#phrasing_content)类别，不过除了这两个还有其他类别。

## 12.JS有几种数据类型

> 【MDN】[数据结构和类型](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Guide/Grammar_and_Types#%E6%95%B0%E6%8D%AE%E7%BB%93%E6%9E%84%E5%92%8C%E7%B1%BB%E5%9E%8B)
> 
> 最新的 ECMAScript 标准定义了 8 种数据类型：
> 
> -   七种基本数据类型：
> 
> -   布尔值（Boolean），有 2 个值分别是：true 和 false.
> -   null，一个表明 null 值的特殊关键字。JavaScript 是大小写敏感的，因此 null 与 Null、NULL或变体完全不同。
> -   undefined，和 null 一样是一个特殊的关键字，undefined 表示变量未赋值时的属性。
> -   数字（Number），整数或浮点数，例如： 42 或者 3.14159。
> -   任意精度的整数 (BigInt) ，可以安全地存储和操作大整数，甚至可以超过数字的安全整数限制。
> -   字符串（String），字符串是一串表示文本值的字符序列，例如："Howdy" 。
> -   代表（Symbol）( 在 ECMAScript 6 中新添加的类型).。一种实例是唯一且不可改变的数据类型。
> 
> -   以及对象（Object）。

## 14.连续对象赋值

```javascript
var a = {
  n: 0,
};
var b = a;
a.n = a = { n: 1 };
console.log(b.n); // { n: 1 }
```
> -   创建一个对象a
> 
> -   开辟一个地址 address1 【 { n: 1 } 】, 变量a:address1
> 
> -   变量a赋值给变量b
> 
> -   变量b:address1
> 
> -   a.n = a = { n:1 }
> 
> -   a = { n:1 }
> 
> -   开辟了一个新地址 address2【 { n：1 } 】 ,变量 a:address2
> 
> -   a.n = a = { n:1 }
> 
> -   赋值表达式的运算结果就是就是所赋的值：即address2
> -   address1 【 { n : address2 } 】
> 
> -   结果打印的就是 address2

## 16.求余和求模

> -   求余： x rem y = x - fix( x / y ) \* y
> 
> -   fix： 向0取整
> 
> -   2.5 -> 2
> -   \-2.5 -> -2
> 
> -   求模： x mod y = x - floor( x / y ) \* y
> 
> -   floor : 向下取整
> 
> -   2.5 -> 2
> -   \-2.5 -> -3

## 17.递归求和

```javascript
/**
 * 数组求和
 * @param {Array} arr 目标数组
 * @param {number} [i=0] 开始索引
 * @return {Number}  
 */
function sum(arr, i = 0) {
  if (i === arr.length - 1) {
    return arr[i];
  }
  return arr[i] + sum(arr, i + 1);
}
console.log(sum([1,2,3]));
```

## 49.各种隐藏方式的区别

|  | display:none | visibility:hidden | opacity:0 |
| --- | --- | --- | --- |
| 是否生成盒子 | ❌ | ✔️ | ✔️ |
| 是否占据空间 | ❌ | ✔️ | ✔️ |
| 是否可以交互 | ❌ | ❌ | ✔️ |
| 是否参与reflow | ❌ | ✔️ | ✔️ |
| 是否参与repaint | ❌ | ❌ | ✔️ |
