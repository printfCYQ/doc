### 1.格式化数字

```javascript
const str = (123456789 + '').replace(/(?!^)(?=(\d{3})+$)/g, ',')
console.log(str) //123,456,789
```

### 格式化手机号

```javascript

const formatMobile = (mobile) => {
  return String(mobile).slice(0,11)
      .replace(/(?<=\d{3})\d+/, ($0) => '-' + $0)
      .replace(/(?<=[\d-]{8})\d{1,4}/, ($0) => '-' + $0)
}

console.log(formatMobile(18379836654))
```

### 2.密码组合(数字和字母，数字和符号，字母和符号，字母和数子和符号，且长度要在8-19位之间)

```javascript
^(?=.*\d)(?=.*[a-zA-Z])(?=.*[!@#$%^&*(),.?":{}|<>]).{8,19}$
```

### 3.邮箱

您好！如果您需要使用 JavaScript 正则表达式来验证电子邮件地址，可以使用以下代码：

  

```plain
const email = "example@email.com";
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

if (emailRegex.test(email)) {
  console.log("这是一个有效的电子邮件地址");
} else {
  console.log("这不是一个有效的电子邮件地址");
}
```

  

在上面的代码中，我们使用了 `test()` 方法来检查电子邮件地址是否符合正则表达式。该正则表达式的含义是：

  

-   `^` 表示字符串的开头
-   `[^\s@]+` 表示一个或多个非空格和非 `@` 符号的字符
-   `@` 表示 `@` 符号
-   `[^\s@]+` 表示一个或多个非空格和非 `@` 符号的字符
-   `\.` 表示一个点号
-   `[^\s@]+` 表示一个或多个非空格和非 `@` 符号的字符
-   `$` 表示字符串的结尾

  

这个正则表达式的意思是：电子邮件地址必须包含一个 `@` 符号和一个点号，并且 `@` 符号和点号之间必须有一个或多个非空格字符。如果电子邮件地址符合这个正则表达式，那么它就是一个有效的电子邮件地址。
