# 区别

## 区别

> isNaN 和 Number.isNaN 是 JavaScript 中用于检测一个值是否为 NaN 的两个函数。
> `isNaN` 函数：
> 
> -   isNaN 函数用于检测一个值是否为 NaN（Not a Number）。
> -   如果传入的值不是数字类型或者无法被转换为数字，则返回 true。
> -   如果传入的值是数字类型且可以被转换为数字，则返回 false。
> -   但是，isNaN 函数在进行类型转换时会自动将非数字类型的值尝试转换成数字，可能会导致一些意外的结果。例如，isNaN('abc') 会返回 true，因为字符串 'abc' 无法被转换为数字。
> `Number.isNaN` 函数：
> 
> -   Number.isNaN 函数也用于检测一个值是否为 NaN。
> -   如果传入的值是数字类型且为 NaN，则返回 true。
> -   如果传入的值是数字类型但不是 NaN（如 Infinity、-Infinity），或者是非数字类型的值，则返回 false。
> -   Number.isNaN 函数不会进行类型转换，只有在传入的值本身为 NaN 时才返回 true。
---

## 示例

以下是一些示例来说明两个函数之间的区别：

```javascript
isNaN(NaN);           // true
isNaN(10);            // false
isNaN('abc');         // true, 会进行类型转换，'abc' 无法转换成数字

Number.isNaN(NaN);    // true
Number.isNaN(10);     // false
Number.isNaN('abc');  // false, 不会进行类型转换，'abc' 不是 NaN
```
> 综上所述，Number.isNaN 更加准确地检测一个值是否为 NaN，而 isNaN 在进行类型转换时可能会返回意外的结果。如果你只需要检测一个值是否为 NaN，推荐使用 Number.isNaN。
