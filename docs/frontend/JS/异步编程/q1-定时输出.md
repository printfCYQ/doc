# q1-定时输出

> **两个代码段的区别**
```javascript
setInterval(() => {
  console.log(1);
}, 1000)

function fn() {
  setTimeout(() => {
    console.log(1);
    fn()
  }, 1000)
}
fn()
```
> **更改后-两个代码段的区别**
```javascript
function pause(ms) {
    const start = new Date().getTime();
    while (new Date().getTime() < start + ms);
}

let start = new Date().getTime();
setInterval(() => {
    console.log('time:', new Date().getTime() - start);
    pause(300)
    start = new Date().getTime();
}, 1000)

let start = new Date().getTime();
function fn() {
    setTimeout(() => {
        console.log('time:', new Date().getTime() - start);
        pause(300)
        start = new Date().getTime();
        fn()
    }, 1000)
}
fn()
```
> 第一段会阻塞整个线程，第二段代码不会阻塞线程。
> 
> 第一段代码会在暂停期间阻塞其他代码的执行，而第二段代码不会阻塞其他代码的执行。
> 
> 在实际应用中，建议使用第二段代码，以避免阻塞线程。
