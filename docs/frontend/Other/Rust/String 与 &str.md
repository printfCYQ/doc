# String 与 &str

> ​`String` 是 Rust 语言中的一种字符串类型，它是一个可增长、可变的字符序列。它在堆上分配内存，并提供了一系列的方法来操作字符串，例如，连接、插入、替换、删除等。此外，`String` 类型是 UTF-8 编码的，这意味着它可以处理世界上大多数语言的字符。
> 
> 而 `&str` 是一个字符串切片类型，它是对 `String` 或其他字符串类型的引用。它允许你访问字符串的一部分，而不需要复制整个字符串。`&str` 类型通常用于函数参数和返回值，因为它比 `String` 类型更高效，因为它避免了复制字符串所带来的额外开销。
> 
> 下面是 `String` 和 `&str` 的一些主要区别：
> 
> 1.  所有权和可变性：`String` 类型拥有它所包含的字符序列的所有权，并且是可变的，这意味着你可以修改字符串的内容。而 `&str` 是一个切片，它指向一个已有的字符串，并且它所指向的字符串内容不能被修改。它只提供对字符串的读取访问。
> 2.  生命周期：`String` 类型的生命周期由其所在的作用域决定，当它离开作用域时，它的资源会被自动释放。`&str` 类型的生命周期则是它所引用的字符串的生命周期的一部分，当它的所有者离开作用域或者它所引用的字符串被释放时，它也将不再可用。
> 3.  使用场景：`String` 类型适用于需要创建、修改或拥有字符串所有权的场景。例如，当你需要从用户输入构建字符串，或者在某个算法中需要动态地修改字符串内容时，使用 `String` 类型是合适的。`&str` 类型适用于只读的字符串操作，例如，当你需要将一个字符串作为参数传递给函数，或者从一个 `String` 对象中提取子字符串时，使用 `&str` 类型是一个好的选择。
> 4.  效率：由于 `&str` 类型是只读的，并且不需要复制整个字符串，它在处理大型字符串或者需要频繁传递字符串作为参数时，可以显著地减少内存的使用和复制的开销。
> 5.  方法和操作：`String` 类型提供了一套丰富的方法来操作字符串，如 `push`、`pop`、`insert`、`remove`、`len`、`is_empty` 等。`&str` 类型则没有这些方法，因为它是只读的。但是，它可以使用字符串切片的操作来获取子串、切片、迭代字符等。
> 
> 在实际编程中，你可以根据具体的需求来选择使用 `String` 还是 `&str`。如果你需要修改字符串或者拥有其所有权，使用 `String`。如果你只需要读取字符串内容，并且希望更高效地使用内存，`&str` 是更好的选择。在函数参数传递中，如果字符串内容不需要修改，使用 `&str` 作为参数类型，可以避免不必要的复制。

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = "hello world".to_string();
    let s3 = "rust".to_owned();
    println!("s1: {}, s2: {}, s3: {}", s1, s2, s3);
    println!("------------------------------------");

    let s1_new = s1 + " world";
    let s2_new = s2.replace("world", "rust");
    println!("s1_new: {}, s2_new: {}", s1_new, s2_new);
    println!("------------------------------------");

    let s4 = "\x52\x75\x73\x74";
    let s5 = "\u{52}\u{75}\u{73}\u{74}";
    let s6 = "hahaha";
    println!("s4: {}, s5: {}, s6: {}", s4, s5, s6);
    println!("------------------------------------");
}
```

```rust
// 参数可以是&str 或者 &String
fn print_str(string: &str) {
    println!("print_str {}", string);
}

// 参数可以是&String 不能是 &str
fn print_string(string: &String) {
    println!("print_string {}", string);
}

fn main() {
    let s1 = "Hello".to_string();
    let s2 = "World";

    print_str(&s1);
    print_str(s2);

    print_string(&s1);
    // print_string(s2); // expected `String`, found `&str`
}
```
