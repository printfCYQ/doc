# 元组与数组

> -   元组与数组
> 
> -   相同点
> 
> -   1.元组和数组都是`Compound Types`,而`Vec`和`Map`都是`Collection Types`
> -   2.元组和数组长度都是固定的
> 
> -   不同点
> 
> -   `Tuples`不同类型的数据类型
> -   `Arrays`同一类型的数据类型
> -   数组（`Array`）
> 
> -   数组是一个固定大小的集合，这意味着它可以容纳特定数量的元素，这个数量在编译时就已经确定。
> -   数组中的元素类型必须相同。
> -   数组是用方括号`[]`来声明的，元素之间用逗号分隔。
> -   数组中的元素可以通过索引访问，索引从0开始。
> -   数组作为参数传递给函数时，整个数组会被复制。
> 
> -   元组（`Tuple`）
> 
> -   元组是一个固定大小的集合，它可以容纳不同类型的元素。
> -   元组中的元素数量和类型在编译时确定。
> -   元组使用圆括号`()`来声明，元素之间用逗号分隔。
> -   元组中的元素可以通过模式匹配来访问，也可以通过索引访问，但索引从0开始。
> -   元组作为参数传递给函数时，整个元组会被复制。



```rust
fn main() {
    let numbers: [i32; 5] = [10, 20, 30, 40, 50];
    let first_number = numbers[0];
    let second_number = numbers[1];

    println!("numbers first number is: {}", first_number);
    println!("numbers second number is: {}", second_number);
    println!("----------------------------------------------");

    let numbers2: [i32; 2] = [10; 2];
    println!("numbers2: {} {}", numbers2[0], numbers2[1]);
    println!("numbers2 len {}", numbers2.len());

    for num in numbers2 {
        println!("num: {}", num)
    }
    println!("----------------------------------------------");

    let person: (&str, i32, f32) = ("Alice", 30, 175.5);
    let name = person.0;
    let age = person.1;
    let height = person.2;

    println!("person name is: {}", name);
    println!("person age is: {}", age);
    println!("person height is: {}", height);
    println!("----------------------------------------------");

    let mut person2: (char, i32, f32) = ('A', 30, 175.5);
    println!("before person2 name is: {}", person2.0);
    person2.0 = 'B';
    println!("after person2 name is: {}", person2.0);
}
```

> 所有权（`Ownership`）在Rust中是一个核心概念，它确保了内存安全和资源的正确管理，主要的特点有：
> 
> 1.  每个值都有一个所有者，这个所有者是负责管理值的生命周期的变量。
> 2.  所有权可以通过多种方式转移，通常是在将值传递给另一个变量或函数时发生。
> 3.  当所有者离开作用域时，Rust会自动释放它所拥有的值的资源。
> 
> Rust中的所有权遵循以下基本原则：
> 
> 1.  变量拥有它的值的所有权。
> 2.  所有权可以通过移动（Move）或复制（Copy）来传递。
> 3.  移动会导致原变量失去对值的所有权，复制则不会。
> 4.  当拥有者（变量）离开作用域或者生命周期结束时，Rust 会自动通过 drop 机制释放拥有者所有的资源。
> 
> 所有权规则使得Rust在编译时能够静态地检查资源的释放，确保不会出现悬挂指针（dangling pointer）或内存泄漏（memory leak），从而提供内存安全的保证。
> 
> 所有权概念使得Rust编译器可以在编译时检查代码中潜在的内存访问问题，帮助开发者编写更加健壮和可靠的代码。



```rust
fn main() {
    let number1 = 10;
    let number1_copy = number1; // copy
    println!("number1: {}, number1_copy: {}", number1, number1_copy);

    let string = String::from("Hello");
    let string_move = string; // move string被销毁
    // println!("string: {}", string); // value borrowed here after move
    println!("string_move: {}", string_move);
}
```
