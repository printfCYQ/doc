# 函数值参数传递、不可变借用参数传

> **函数值参数传递(Move)**
> 
> -   函数的代码本身通常是存储在可执行文件的代码段，而在调用时函数会在栈上开辟一个新的stack frame(栈空间)，用于存储函数的局部变量、参数和返回地址等信息，而当函数结束后会释放该空间。
> 
> -   而当传入non-Copy value(Vec、String等)
> 
> -   传入函数时实参会转移value的所有权给形参，实参会失去value的所有权。
> -   而在函数结束时，value的所有权会释放。
> **不可变借用**
> 
> -   如果你不想失去valuel的所有权，你又没有修改value的需求，你可以使用不可变借用。
> -   在Rust中，你可以将不可变引用作为函数的参数，从而在函数内部访问参数值但不能修改它。这有助于确保数据的安全性，防止在多处同时对数据进行写操作，从而避免数据竞争。
> 
> -   如何应用不可变借用。
> 
> -   `Use * to deference`,去获取其的值。
> **可变借用**
> 
> -   如果你有修改值的需求你可以使用可变借用，以允许在函数内部修改参数的值。这允许函数对参数进行写操作，但在同一时间内只能有一个可变引用。。
> -   需要在形参前加&mut。
> -   如何应用可变借用
> 
> -   同样使用`Use * to deference`,去获取其的值。
```rust
fn move_fn(p1: i32, p2: String) {
    println!("move_fn p1: {}, p2: {}", p1, p2);
}

fn print_value(value: &i32) {
    println!("print_value value: {}", value);
}

fn string_fn_borrow(value: &String) {
    println!("string_fn_borrow value: {}", (*value).to_uppercase());
}

fn main() {
    let p1 = 10;
    let p2 = "hello".to_string();
    move_fn(p1, p2); // p1: 10, p2: hello
    println!("p1: {}", p1); // p1: 10
    // println!("p2: {}", p2); // value borrowed here after move

    let n1 = 20;
    print_value(&n1); // print_value value: 20
    println!("n1: {}", n1); // n1: 20

    let s1 = String::from("hello");
    string_fn_borrow(&s1); // s1: HELLO
    println!("s1: {}", s1); // s1: hello
}
```
```rust
#[derive(Debug)]
struct Point {
    x: i32,
    y: i32,
}

fn modify_point(point: &mut Point) {
    (*point).x += 1;
    point.y += 1;
}
fn main() {
    let mut point = Point { x: 5, y: 10 };
    println!("原始点: {:?}", point); // 原始点: Point { x: 5, y: 10 }

    modify_point(&mut point);

    println!("修改后的点: {:?}", point); // 修改后的点: Point { x: 6, y: 11 }
}
```
