# 函数返回值与所有权机制

> 在Rust中，函数的返回值是函数执行完毕后返回给调用者的结果。这与其他编程语言中的函数返回值概念类似。Rust中的返回值可以是任何类型，包括基本类型（如整数、浮点数、布尔值等）、复合类型（如结构体、枚举、元组等）以及指针类型。
> 
> 以下是一个简单的Rust函数示例，该函数接受两个整数参数并返回它们的和：
```rust
fn add_two_numbers(num1: i32, num2: i32) -> i32 {
    num1 + num2
}

fn main() {
    let result = add_two_numbers(5, 3);
    println!("结果: {}", result); 
}
```
> 在这个例子中，`add_two_numbers` 函数返回类型被声明为 `i32`，这意味着它将返回一个 `i32` 类型的整数。函数体中的代码 `num1 + num2` 计算两个整数的和，并将结果作为函数的返回值。在 `main` 函数中，`result` 变量将存储 `add_two_numbers` 函数调用后的返回值，即 `8`。
> 
> Rust还支持返回多个值，这可以通过元组（`Tuple`）类型来实现。元组是一个固定大小的有序列表，其中包含不同类型的元素。下面是一个返回元组的函数示例：
```rust
fn get_name_and_age() -> (String, u32) {
    ("Alice", 30)
}

fn main() {
    let (name, age) = get_name_and_age();
    println!("姓名是: {}", name); 
    println!("年龄是: {}", age); 
}
```
> 在这个例子中，`get_name_and_age` 函数返回一个元组，其中包含一个 `String` 类型的元素（表示姓名）和一个 `u32` 类型的元素（表示年龄）。在 `main` 函数中，这两个返回值被直接解构（`destructure`）到两个变量 `name` 和 `age` 中，使得它们可以被分别使用和打印。
> 
> 总的来说，Rust函数的返回值通过返回类型来指定，可以返回单个值或多个值。在调用函数时，返回值随后可以被接收和处理，从而允许函数将信息传递回调用函数的代码块。
---
> **返回Copy与Non-Copy**
> 
> 都可以返回，但是要注意`Non-Copy`是在堆上的
> 
> 性能：
> 
> -   在一般情况下，返回Copy类型的值通常具有更好的性能。这是因为Copy类型的值是通过复制进行返回的，而不涉及堆上内存的分配和释放，通常是在栈上分配。这样的操作比涉及堆上内存的分配和释放更为高效。
---
> **返回引用**
> 
> -   在只有传入一个引用参数，只有一个返回引用时，生命周期不需要声明
> -   其他情况下需要声明引用的生命周期
> -   慎用`'statc`
---
```rust
fn func_copy_back() -> i32 {
    let n = 10;
    n
}

fn func_non_copy_back() -> String {
    let s = String::from("hello");
    s
}

fn get_mess(mark: i32) -> &'static str {
    if mark == 100 {
        "😄"
    } else {
        "😥"
    }
}

fn main() {
    let n = func_copy_back();
    println!("n = {}", n);

    let s = func_non_copy_back();
    println!("s = {}", s);
    
    let mark = 100;
    println!("{}", get_mess(mark));
}
```
