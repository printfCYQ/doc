# 变量与不可变性

> 1.在`Rust`中，使用`let`关键字来声明变量
> 
> 2.`Rust`支持类型推导，但你也可以显式指定变量的类型：
> 
> `let x:i32 = 5;`// 显式指定`x`的类型为`i32`
> 
> 3.变量名蛇形命名法(`Snake Case` [`hello_world`])，
> 
> 而枚举和结构体命名使用帕斯卡命名法(`Pascal Case`[`HelloWorld`]),
> 
> 如果变量没有用到可以前置下划线，消除警告。
> 
> -   帕斯卡命名法（Pascal Case），也称为大驼峰命名法（Upper Camel Case）
> 
> 4.强制类型转换`Casting a Value to a Different Type`
> 
> `let a = 3.1; let b = a as i32;`
> 
> 5.打印变量(`{}`与`{:?}`需要实现特质之后章节会介绍，基础类型默认实现)
> 
> -   `println!("val: {}", x);`
> -   `println!("val: {x}");`
> **Rust中的变量是默认不可变的**
> 
> 在 `Rust` 中，变量默认是不可变的，这是 `Rust` 语言的一个设计特性，也是其安全和并发模型的一个基础。这个特性意味着一旦一个变量被声明并初始化，它的值就不能被改变，除非使用特定的关键字或语法来标记它为可变的。 这种设计决策有几个重要的原因和好处：
> 
> -   内存安全：不可变变量确保了数据的完整性。一旦一个值被分配给一个变量，它就不会被意外地修改，从而减少了`悬挂指针`、`空指针`引用和`内存泄漏`的可能性。
> -   线程安全：在多线程环境中，不可变变量使得代码的推理更加简单。因为它们不能被修改，所以不需要使用互斥锁或其他同步机制来保护它们。这有助于避免死锁和竞态条件，提高并发代码的性能。
> -   代码的可维护性：不可变变量有助于编写清晰、易于维护的代码。它们使得函数的行为更可预测，减少了副作用，从而提高了代码的可读性。
> -   函数式编程：支持函数式编程风格，其中函数的输出仅依赖于其输入，而不依赖于外部状态。这使得代码的测试和推理更加简单。 如果确实需要修改变量的值，Rust 提供了`mut`关键字来标记变量为可变的。这使得变量可以被修改，但同时也需要开发者在代码中显示地管理这种可变性，增强了代码的安全性。 总的来说，变量默认不可变是 Rust 语言的一个独特特性，它有助于编写安全、可靠和高效的代码。
> 
> **使用**`**mut**`**关键字进行可变声明**
> 
> `let mut x = 1; // 可变变量`
> 
> `x = 2; // 合法的修改`
> `**Shadowing Variables**`**并不是重新赋值**
> 
> Rust允许您隐藏一个变量，这意味着您可以声明一个与现有变量同名的新变量，
> 
> 从而有效地隐藏前一个变量
> 
> -   可以改变值
> -   可以改变类型
> -   可以改变可变性
---
```rust
fn main() {
    // 不可变变量
    let x = 5; // 自动推断类型为 i32
    let _y: i64 = 10; // 显式指定类型为 i64, _ 定义一个未使用的变量
    println!("The value of x is: {}", x); // 5

    // 可变变量
    let mut _z = 10;
    _z = 20; // 赋值
    println!("The value of z is: {}", _z); // 20

    // Shadowing
    let a = 5;
    {
        // 在这个作用域中，a 被重新赋值为 10
        let a = a * 2;
        println!("The value of a in the inner scope is: {}", a); // 10
    } // 内部 a 的作用域结束，被销毁
    let a = a + 1; // 重新赋值为 6
    println!("The value of a in the outer scope is: {}", a); // 6

    // 改变类型
    let _b = 1;
    let _b: &str = "hello"; // 改变类型为 &str
    println!("The value of b is: {}", _b); // hello

    // 常量
    const MAX_VALUE: i32 = 100;
    println!("The value of MAX_VALUE is: {}", MAX_VALUE); // 100
}

```
