# 枚举与匹配模式

> 在Rust中，枚举（Enumeration）是一种类型，它允许你为一组相关的值赋予一个类型。枚举是一等公民类型，可以像其他类型一样使用。 枚举的一个主要用途是确保代码的可读性和维护性。通过定义一个枚举，你可以清晰地表达代码中某个值的含义和可能的状态。 例如，如果你在开发一个游戏，你可能有一个枚举来表示游戏角色的职业，如：
```rust
enum CharacterClass {
    Warrior,
    Mage,
    Archer,
}
```
> 这样，在你的代码中，每当你看到`CharacterClass::Warrior`，你就知道它代表着“战士”这个职业，而不是一个随机的整数或者字符串。 枚举也可以包含数据，每个变体（variant）都可以有与之关联的特定数据结构。例如，我们可以扩展上述的`CharacterClass`枚举，使其包含每个职业的统计信息：
```rust
enum CharacterClass {
    Warrior { strength: u32 },
    Mage { intelligence: u32 },
    Archer { dexterity: u32 },
}
```
> 在这个例子中，每个枚举变体都关联了一个特定的属性，这些属性可以被用来定义角色的特性。 使用枚举有以下优点：
> 
> 1.  类型安全：Rust的类型系统确保你只能使用有效的枚举变体，减少了错误的可能性。
> 2.  模式匹配：Rust中的`match`表达式可以用来处理枚举变体，使得代码更加简洁和安全。
> 3.  扩展性：你可以轻松地在现有枚举中添加新的变体，而不需要修改所有使用该枚举的代码。
> 4.  文档化：枚举及其变体为代码提供了自文档化的元素，使得其他开发者更容易理解你的意图。
> 5.  代码组织：枚举帮助你组织相关的常量值，提供了一个清晰的命名空间，避免了全局常量的混乱。

```rust
enum Color {
    Red,
    Blue,
    Green,
    Black,
}

fn print_color(color: Color) {
    match color {
        Color::Red => println!("Red"),
        Color::Blue => println!("Blue"),
        Color::Green => println!("Green"),
        _ => println!("Unknown color"),
    }
}

fn main() {
    print_color(Color::Red);
    print_color(Color::Blue);
    print_color(Color::Black);
}
```

```rust
enum BuildingLocation {
    Name(String),
    Number(i32),
    Unknown,
}

impl BuildingLocation {
    fn print(&self) {
        match self {
            BuildingLocation::Name(name) => println!("Name {}", name),
            BuildingLocation::Number(number) => println!("Number {}", number),
            BuildingLocation::Unknown => println!("Unknown"),
        }
    }
}

fn main() {
    let building_location1 = BuildingLocation::Name(String::from("123 Main St"));
    building_location1.print();

    let building_location2 = BuildingLocation::Number(123);
    building_location2.print();

    let building_location3 = BuildingLocation::Unknown;
    building_location3.print();
}
```
