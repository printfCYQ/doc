# 结构体、方法、关联函数、关联变量

> 在 Rust 中
> 
> -   结构体（struct）是一种自定义数据类型，它允许你组合相关的字段，形成一个有意义的实体。
> -   方法（method）是与结构体实例关联的函数，它们允许你对结构体的实例执行特定的操作。
> -   关联函数（associated function）是与结构体或枚举类型关联的函数，但它们与特定的实例无关。
> -   关联变量（associated constant）是与结构体或枚举类型相关联的常量。
> 
> 这些特性使得结构体在 Rust 中成为一个非常强大和灵活的编程工具，它们为代码的模块化、可读性和维护性提供了极大的便利。
```rust
enum Flavor {
    Vanilla,
    Chocolate,
    Strawberry,
}

struct Drink {
    flavor: Flavor,
    price: f64,
}

fn parint_drink(drink: Drink) {
    match drink.flavor {
        Flavor::Vanilla => println!("Vanilla"),
        Flavor::Chocolate => println!("Chocolate"),
        Flavor::Strawberry => println!("Strawberry"),
    }
}

fn main() {
    let drink = Drink {
        flavor: Flavor::Vanilla,
        price: 1.0,
    };
    println!("Drink price: {}", drink.price);
    parint_drink(drink);
}
```



```rust
enum Flavor {
    Vanilla,
    Chocolate,
    Strawberry,
}

struct Drink {
    flavor: Flavor,
    price: f64,
}

fn parint_drink(drink: Drink) {
    match drink.flavor {
        Flavor::Vanilla => println!("Vanilla"),
        Flavor::Chocolate => println!("Chocolate"),
        Flavor::Strawberry => println!("Strawberry"),
    }
}

impl Drink {
    // 关联变量
    const MAX_PRICE: f64 = 10.0;
    
    // 方法
    fn by(&self) {
        if self.price > Drink::MAX_PRICE {
            println!("Too expensive");
            return;
        }
        println!("buy it");
    }
    
    // 关联函数
    fn new(flavor: Flavor, price: f64) -> Self {
        Drink { flavor, price }
    }
}

fn main() {
    let drink = Drink {
        flavor: Flavor::Vanilla,
        price: 1.0,
    };
    println!("Drink price: {}", drink.price);
    parint_drink(drink);
    println!("------------------------------------------------------");
    
    let drink = Drink {
        flavor: Flavor::Chocolate,
        price: 16.0,
    };
    drink.by();
    println!("------------------------------------------------------");
    
    let drink = Drink::new(Flavor::Strawberry, 1.0);
    println!("Drink price: {}", drink.price);
    println!("------------------------------------------------------");
}
```
