# 项目结构

```powershell
cargo new --lib <lib-name>
```
> `cargo new --lib &lt;lib-name>` 是一个用于创建新 `Rust` 库项目的命令。它使用 `Cargo` 构建工具来初始化一个新的 `Rust` 项目，并生成一个基本的项目结构。
> 
> 该命令中的 `--lib` 参数指定了创建的项目类型为库，而 `&lt;lib-name>` 则是指定创建的库项目的名称。
> 
> 运行该命令后，`Cargo` 将在当前目录下创建一个新的文件夹，文件夹名称为`&lt;lib-name>`，并在其中生成一个基本的 `Rust` 库项目结构。该项目结构包括一个 `src` 目录，其中包含一个同名的 `Rust`源文件，用于编写库的代码。
> 
> 您可以在生成的项目中编写库的代码，并使用 `Cargo` 来构建、测试和运行该库项目。
