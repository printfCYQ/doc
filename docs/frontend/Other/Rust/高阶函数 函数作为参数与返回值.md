# 高阶函数 函数作为参数与返回值

```rust
fn func_twice(f: fn(i32) -> i32, x: i32) -> i32 {
    f(f(x))
}

fn fn_mul(x: i32) -> i32 {
    x * x
}

fn fn_add(x: i32) -> i32 {
    x + 1
}

fn main() {
    let n1 = 2;
    let result1 = func_twice(fn_mul, n1);
    println!("结果: {}", result1); // 16

    let n2 = 3;
    let result2 = func_twice(fn_add, n2);
    println!("结果: {}", result2); // 5
}
```
---
```rust
fn main() {
    let numbers1 = [10, 20, 30, 40, 50];
    let map_res: Vec<i32> = numbers1.iter().map(|number| number * number).collect();
    println!("{:?}", map_res); // [100, 400, 900, 1600, 2500]

    let numbers2 = [10, 20, 30, 40, 50];
    let filter_res: Vec<i32> = numbers2.into_iter().filter(|&number| number > 30).collect();
    println!("{:?}", filter_res); // [40, 50]

    let numbers3 = [10, 20, 30, 40, 50];
    let reduce_res: i32 = numbers3
        .into_iter()
        .reduce(|acc, number| acc + number)
        .unwrap();
    println!("{:?}", reduce_res); // 150

    let numbers4 = [10, 20, 30, 40, 50];
    let reduce_res: i32 = numbers4.iter().fold(0, |acc, &number| acc + number);
    println!("{:?}", reduce_res); // 150
}
```
> 在Rust中，`iter`上的`reduce`和`fold`方法的行为基本相同。它们都允许你将迭代器中的元素通过指定的操作合并成一个单一的值。如果你没有提供初始值，`reduce`将使用迭代器中的第一个元素作为初始值，这与`fold(initial_value)`效果类似，只是`initial_value`默认为迭代器中的第一个元素。
