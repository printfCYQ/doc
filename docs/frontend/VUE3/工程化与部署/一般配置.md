# 一般配置

## 一般配置

```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

// https://vitejs.dev/config/
export default defineConfig({
  plugins: [vue()],
  build: {
    rollupOptions: {
      output: {
        manualChunks: {
          test: ['vue', 'lodash']
        }
      }
    }
  }
})

```
> 'vue', 'lodash' 模块打包到一个文件内，其他文件打包到一个文件



> 当修改其他文件后，再打包，'vue', 'lodash' 模块打的包未修改 【名字不会改变】【用户不需要重新请求】



## 通用配置

```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

// https://vitejs.dev/config/
export default defineConfig({
  plugins: [vue()],
  build: {
    rollupOptions: {
      output: {
        manualChunks(id){
          // @ts-ignore
          if(id.includes('node_modules')){
            return 'vendor'
          }
        }
      }
    }
  }
})

```
> 将第三方包打包到一起【第三方包不会改动】。
