# v-if && v-show

> -   v-if
> 
> 1.  真条件渲染（即要什么给什么）
> 2.  开销大
> 3.  适合低频操作
> 4.  节省内存
> 5.  可以处理 else

  

> -   v-show
> 
> 1.  假条件渲染（即一次全部给）
> 2.  开销小
> 3.  适合高频操作
> 4.  费内存
> 5.  无法处理 else

​  

​  

> v-if 是 创建一个dom节点
> 
> v-show 是 display:none/block

​  

​  

> 初次加载v-if要比v-show好，页面不会做加载盒子
> 
> 频繁切换v-show要比v-if好，不用频繁的创建和删除dom节点
