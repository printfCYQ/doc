# 局部组件

> 一个组件内通过import 去引入别的组件 称之为局部组件。

# 全局组件

> main.ts 内注册。
> 
> 注册后，不用再需要import。

## 单组件

```vue
import { createApp } from 'vue'
import './style.css'
import App from './App.vue'
import Child from './components/Child.vue'

const app = createApp(App)
app.component('Child', Child)
app.mount('#app')
```

## 批量

> 参考 `element Plus`

```vue
import * as ElementPlusIconsVue from '@element-plus/icons-vue'

const app = createApp(App)
for (const [key, component] of Object.entries(ElementPlusIconsVue)) {
  app.component(key, component)
}
```

# 递归组件

> 自己调用自己。
> 
> 通过一个条件来结束递归。

## 案例-Tree

  

```vue
<template>
  <div>
    <Child :data="data"></Child>
  </div>
</template>

<script setup lang="ts">
import { reactive } from 'vue';
type TreeList = {
  name: string;
  checked?: boolean;
  children?: TreeList[] | [];
};
const data = reactive<TreeList[]>([
  {
    name: "no.1",
    checked: false,
    children: [
      {
        name: "no.1-1",
        checked: false,
        children: [
          {
            name: "no.1-1-1",
            checked: false,
          },
        ],
      },
    ],
  },
  {
    name: "no.2",
    children: [
      {
        name: "no.2-1",
        checked: true,

      },
    ],
  },
  {
    name: "no.3",
    checked: false,
  },
]);
</script>
```
```vue
<template>
    <div class="tree" v-for="item in data" @click.stop="clickItem($event, item)">
        <input type="checkbox" :checked="item.checked"><span>{{ item.name }}</span>
        <Child v-if="item.children?.length" :data="item.children"></Child>
    </div>
</template>

<script setup lang="ts">
type TreeList = {
    name: string;
    checked?: boolean;
    children?: TreeList[] | [];
};

type Props<T> = {
    data?: T[] | [];
};

defineProps<Props<TreeList>>();

const clickItem = (e: Event, item: TreeList) => {
    console.log(e, item)
}

</script>
<style>
.tree {
    margin-left: 10px;
}
</style>
```



  

# 动态组件

> 让多个组件使用同一个挂载点，并动态切换。
> 
> &lt;component :is="Comp">&lt;/component>

## 案例-Tabs

```vue
<template>
  <div>
    <div v-for="item in data" :key="item.name" @click="handelitem(item)">{{ item.name }}</div>
    <component :is="componentId"></component>
  </div>
</template>

<script setup lang="ts">
import { reactive, ref } from 'vue'
import A from './A.vue'
import B from './B.vue'

type Tabs = {
  name: string,
  comName: any
}
type Com = Pick<Tabs, 'comName'>

const data = reactive<Tabs[]>([
  { name: 'A组件', comName: A },
  { name: 'B组件', comName: B }
])

let componentId = ref(A)

const handelitem = (item: Tabs) => {
  componentId.value = item.comName
}
</script>
```

> [Vue warn]: Vue received a Component which was made a reactive object. This can lead to unnecessary performance overhead, and should be avoided by marking the component with \`markRaw\` or using \`shallowRef\` instead of \`ref\`.

**这是因为reactive 会进行proxy 代理 而我们组件代理之后毫无用处 节省性能开销 推荐我们使用shallowRef 或者 markRaw 跳过proxy 代理**

```vue
const tab = reactive<Com[]>([{
    name: "A组件",
    comName: markRaw(A)
}, {
    name: "B组件",
    comName: markRaw(B)
}])

```
