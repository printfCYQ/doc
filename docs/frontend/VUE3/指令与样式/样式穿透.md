# 样式穿透

> **vue支持在&lt;style>标签添加scoped属性，这样当前组件的样式只会在当前样式生效。**
> 
> **使用第三方组件库，覆盖默认样式。**

  

> -   如果你使用的是css，没有使用css预处理器，则可以使用>>>，/deep/，::v-deep。
> -   如果你使用的是less或者node-sass，那么可以使用/deep/，::v-deep都可以生效。
> -   如果你使用的是dart-sass，那么就不能使用/deep/，而是使用::v-deep才会生效。
