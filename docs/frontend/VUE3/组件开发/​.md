> TS:ajax

```vue
type NameList = {
    name: string
}

export const ajax = (url: string): Promise<NameList> => {
    return new Promise((resovle) => {
        let xhr: XMLHttpRequest = new XMLHttpRequest()
        xhr.open('GET', url)
        xhr.onreadystatechange = () => {
            if (xhr.readyState === 4 && xhr.status === 200) {
                setTimeout(() => {
                    resovle(JSON.parse(xhr.responseText))
                }, 3000);
            }
        }
        xhr.send(null)
    })
}
```

# 异步组件

-   defineAsyncComponent
-   Suspense - [vue.js](https://cn.vuejs.org/guide/built-ins/suspense.html)

> 将应用分割成小一些的代码块 并且减少主包的体积。。

```vue
<template>
  <div>
    <Suspense>
      <template #default>
        <Child>
          <template #default="{ data }">
            <div v-for="item in data">
              {{ item }}
            </div>
          </template>
        </Child>
      </template>
      <template #fallback>
        <div>loading...</div>
      </template>
    </Suspense>
  </div>
</template>

<script setup lang="ts">
import { defineAsyncComponent } from 'vue';
const Child = defineAsyncComponent(() => import('./Child.vue'))
</script>
```
```vue
<template>
    <div>
        <slot :data="res"></slot>
    </div>
</template>
<script lang="ts" setup>
import { ajax } from '../utils/ajax';
const res = await ajax('./data.json')
</script>
```

> 再打包，代码分包了。解决首次加载，白屏等问题。
