# 匿名插槽

> 插槽就是子组件中的提供给父组件使用的一个占位符，用`&lt;slot>&lt;/slot>` 表示，父组件可以在这个占位符中填充任何模板代码，如 HTML、组件等，填充的内容会替换子组件的&lt;slot>&lt;/slot>标签。

# 匿名插槽

```vue
<template>
  <div>
    <Child>
      <template v-slot>
        <div>
          匿名插槽
        </div>
      </template>
    </Child>
  </div>
</template>

<script setup lang="ts">
import Child from './Child.vue'
</script>
```
```vue
<template>
    <div>
        <slot></slot>
    </div>
</template>
```

# 具名插槽

```vue
<template>
  <div>
    <Child>
      <template v-slot:header>
        <div>
          具名插槽-header
        </div>
      </template>
      <template v-slot>
        <div>
          匿名
        </div>
      </template>
      <template v-slot:footer>
        <div>
          具名插槽-footer
        </div>
      </template>
    </Child>
  </div>
</template>

<script setup lang="ts">
import Child from './Child.vue'
</script>
```
```vue
<template>
    <div>
        <slot name="header"></slot>
        <slot></slot>
        <slot name="footer"></slot>
    </div>
</template>
```

# 作用域插槽

> 子组件动态绑定参数 派发给父组件的slot去使用。

```vue
<template>
  <div>
    <Child>
      <template #header="{ data }">
        <div>
          <div v-for="item in data">
            {{ item }}
          </div>
          具名插槽-header
        </div>
      </template>
      <template #default="{ data }">
        <div v-for="item in data">
          {{ item }}
        </div>
      </template>
      <template #footer>
        <div>
          具名插槽-footer
        </div>
      </template>
    </Child>
  </div>
</template>

<script setup lang="ts">
import Child from './Child.vue';
</script>
```
```vue
<template>
    <div>
        <slot name="header" :data="data"></slot>
        <slot :data="data"></slot>
        <slot name="footer"></slot>
    </div>
</template>
<script lang="ts" setup>
const data = [1, 2, 3, 4, 5]
</script>
```

# 动态插槽

> 动态插槽名字

```vue
<template>
  <div>
    <Child>
      <template #[name]>
        <div>
          header
        </div>
      </template>
      <template #[name2]>
        <div>
          footer
        </div>
      </template>
    </Child>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue';
import Child from './Child.vue';
const name = ref('header')
const name2 = ref('footer')
</script>
```
