# 父-子

> 父组件通过v-bind绑定一个数据，然后子组件通过defineProps接受传过来的值.

# 父->子

## 传字符串

> 字符串类型是不需要v-bind

```vue
<template>
  <div>
    <Child msg="给子组件传参数"></Child>
  </div>
</template>

<script setup lang="ts">
import Child from './Child.vue';
</script>
```
```vue
<template>
    <div>
        child
        {{ msg }}
    </div>
</template>

<script setup lang="ts">
defineProps<{
    msg: string,
}>()
</script>
<!-- <script setup>
defineProps({
    msg: {
        type: String,
        default: ''
    }
})
</script> -->
```

## 其他值

> 需要v-bind 绑定

```vue
<template>
  <div>
    <Child :type="type" :list="list"></Child>
  </div>
</template>

<script setup lang="ts">
import { reactive, ref } from 'vue';
import Child from './Child.vue';
const type = ref<boolean>(false)
const list = reactive<number[]>([1, 2, 3])
</script>
```
```vue
<template>
    <div>
        child
        <hr>
        {{ type }}
        <hr>
        <ul>
            <li v-for="item in list">{{ item }}</li>
        </ul>
    </div>
</template>

<script setup lang="ts">
const props = defineProps<{
    type: boolean,
    list: number[]
}>()
console.log(props.type); // false
console.log(props.list); // Proxy {0: 1, 1: 2, 2: 3}
</script>
```

## withDefaults

> 设置默认值（TS）

```vue
<script setup lang="ts">
const props = withDefaults(defineProps<{
    type: boolean,
    list: number[]
}>(), {
    type: true,
    list: () => [1, 2]
})
</script>
```

# 子->父

## defineEmits

> 通过defineEmits派发一个事件

```vue
<template>
  <div>
    <Child @on-send="getMsg"></Child>
  </div>
</template>

<script setup lang="ts">

import Child from './Child.vue';
const getMsg = (msg: any) => {
  console.log(msg);
}
</script>
```
```vue
<template>
    <div>
        child
        <hr>
        <button @click="sendMsg">sendMsg</button>
    </div>
</template>

<script setup lang="ts">

const emit = defineEmits(['on-send'])

const sendMsg = () => {
    let msg = {
        a: 1,
        b: 2
    }
    emit('on-send', msg)
}
</script>
```

## defineExpose

> 子组件暴露给父组件内部属性。
> 
> 可以通过ref访问。
> 
> 子组件暴露的是个proxy对象。

```vue
<template>
  <div>
    <Child ref="childRef"></Child>
  </div>
</template>

<script setup lang="ts">

import { onMounted, ref } from 'vue';
import Child from './Child.vue';
// InstanceType<typeof Child> 会有代码提示
const childRef = ref<InstanceType<typeof Child>>()

console.log(childRef.value?.a); // undefined

onMounted(() => {
  console.log(childRef.value?.a); //username
})
</script>
```
```vue
<template>
    <div>
        child
        <hr>
    </div>
</template>

<script setup lang="ts">
import { ref } from 'vue';
const a = ref('username')
defineExpose({
    a
})
</script>
```
