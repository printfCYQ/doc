# replace

> 采用replace进行页面的跳转会同样也会创建渲染新的Vue组件，但是在history中其不会重复保存记录，而是替换原有的vue组件；

  

-   router-link

```html
<router-link replace :to="{ name: 'Home' }">Go to Home</router-link>
<router-link replace :to="{ name: 'About' }">Go to About</router-link>
```

-   编程式

```vue
<template>
  <div>
    <button @click="nav">nav</button>
  </div>
</template>

<script setup lang="ts">
  import { useRouter } from 'vue-router';
  const router = useRouter()
  const nav = () => {
    router.replace('/about')
  }
</script>
```

# 历史

> 该方法采用一个整数作为参数，表示在历史堆栈中前进或后退多少步

```vue
<template>
    <div>
        <button @click="next">前进</button>
        <button @click="prev">后退</button>
    </div>
</template>

<script setup lang="ts">
import { useRouter } from 'vue-router';
const router = useRouter()
const next = () => {
    //前进 数量不限于1
    router.go(1)
}

const prev = () => {
    //后退
    router.back()
}
</script>
```
