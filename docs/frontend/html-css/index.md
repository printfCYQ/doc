# HTML / CSS

HTML 与 CSS 基础到进阶学习笔记。新手建议从「基础入门」第一章开始，**边写边在浏览器看效果**，一两天能写出像样的静态页面。

## 学习笔记

- [HTML / CSS 基础入门](./01-basics.md) — 从"网页是什么"讲起，覆盖标签 / 语义化 / 表单 / 选择器 / 盒模型 / Flex / Grid / 定位 / 响应式 / 动画 / 变量，每节带示例和练习
