# Docker Compose

```javascript
docker-compose --version
```
> `docker-compose` 是一个用于定义和运行多个容器的工具。它使用一个单独的 `docker-compose.yml` 配置文件来定义服务、网络和卷等。以下是一些常用的 `docker-compose` 命令：
> 
> -   `docker-compose up`：启动容器，并构建、创建、启动对应的服务。
> -   `docker-compose down`：停止容器，并删除相关的网络、卷和服务。
> -   `docker-compose ps`：列出正在运行的服务。
> -   `docker-compose logs`：显示容器的日志输出。
> -   `docker-compose exec`：在正在运行的容器中执行命令。
> -   `docker-compose build`：构建容器镜像。
> -   `docker-compose restart`：重启容器。
