## 常用命令

-   配置

-   用户名 `git config user.name 'username'`
-   密码 `git config user.email 'xx@xx.com'`

-   拉代码

-   默认分支`git clone URL`
-   指定分支代码 `git clone -b 分支名 URL`

-   查看

-   日志`git log`

-   checkout

-   远程分支拉到本地仓库 `git checkout --track orgin/feature/home`

-   合并代码

-   将`dev`分支日志上的hash值的代码合并到`home`分支 `git cherry-pick hash码`

-   获取新的分支列表

```html
git remote update origin --prune
```
